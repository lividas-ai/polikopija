# UAB Polikopija

Production website for [polikopija.lt](https://www.polikopija.lt/) — metal, plastic, glass and stone fabrication.

## Vercel

1. Open [Import this repo](https://vercel.com/new/clone?repository-url=https://github.com/lividas-ai/polikopija).
2. Framework: leave auto (Nitro / Vite).
3. Build command: `npm run build`
4. Install command: `npm install`
5. Output directory: leave empty
6. Node.js: **22.x**
7. Environment variables: none required

Then **Deploy**. Add `polikopija.lt` under Project → Settings → Domains.

## Local

```bash
npm install
npm run dev
```
